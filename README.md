# Telegram-бот EmSystem by Yevgeniya Em

Бот со сценарием:

`/start` → выбор языка (RU / IT / FR) → главное меню → О курсе / Бесплатный
урок / Работы учеников / FAQ / Купить курс (ссылка на http://emsystem.me/).

## 1. Структура проекта

```
embrowbot/
├── bot.py            # весь код логики бота
├── config.py         # ВСЕ тексты, ссылки, FAQ, языки — правится без знания кода
├── get_file_id.py     # утилита, чтобы получить file_id для видео
├── requirements.txt
├── .env.example
└── assets/
    └── welcome.mp4    # приветственное видео (см. п.3 про размер!)
```

Чтобы поменять любой текст в боте (FAQ, описание курса и т.д.) — правьте
только `config.py`, код в `bot.py` трогать не нужно.

## 2. Языки интерфейса (RU / IT / FR)

Бот полностью поддерживает **3 языка**: русский, итальянский, французский.
Выбор языка на первом экране (`/start`) теперь не просто запоминается —
все дальнейшие тексты, кнопки и FAQ показываются на выбранном языке.

Все переводы лежат в `config.py`, в словаре `TEXTS`:

```python
TEXTS = {
    "ru": { ... },
    "it": { ... },
    "fr": { ... },
}
```

### Как поменять текст на каком-то языке
Найдите нужный ключ внутри `TEXTS["ru"]` / `TEXTS["it"]` / `TEXTS["fr"]`
и отредактируйте строку. Например, чтобы поменять текст про автора в
разделе "О курсе" на итальянском — правьте `TEXTS["it"]["about_caption"]`.

### Как добавить ещё один язык
1. Добавьте код языка в `LANGUAGES` (например `"de": "🇩🇪 Deutsch"`).
2. Скопируйте один из существующих блоков `TEXTS["it"] = {...}`,
   переведите все строки и вставьте под новым кодом языка
   (`TEXTS["de"] = {...}`).
3. Все ключи должны совпадать — проще всего скопировать структуру
   целиком и просто заменить значения.

### Как убрать язык
Удалите его код из `LANGUAGES` и соответствующий блок из `TEXTS`
(например, чтобы вернуть с трёх языков к одному — оставьте только
`"ru": "🇷🇺 Русский"` в `LANGUAGES` и оставьте только `TEXTS["ru"]`,
остальные можно удалить или оставить неиспользуемыми).

### Видео на разных языках
Сейчас видео в разделах "О курсе" и "Бесплатный урок" общее для всех
языков (`VIDEO_ABOUT_PATH` / `VIDEO_LESSON_PATH` в `config.py`). Если
понадобятся разные видеоролики под разные языки — можно расширить эти
переменные до словарей вида `{"ru": "...", "it": "...", "fr": "..."}`
и поправить `send_course_video()` в `bot.py`, чтобы брать путь/file_id
по текущему языку пользователя. Скажите, если нужно — сделаю.

## 3. Как использовать существующего бота @MethodEmbrowBot

Токен менять не обязательно — можно продолжить использовать того же бота:

1. Откройте Telegram → @BotFather → `/mybots` → выберите **@MethodEmbrowBot**.
2. `API Token` → скопируйте текущий токен (или `Revoke current token`,
   если хотите выпустить новый — например, если старый токен "утёк").
3. Вставьте токен в `.env` (см. `.env.example`) как `BOT_TOKEN=...`.

**Важно:** старый функционал бота (если он был на другом коде/сервере)
нужно остановить — иначе два процесса с одним токеном будут конфликтовать
(Telegram разрешает только один активный polling-процесс на бота).

## 4. Про видео — обязательно прочитайте

У обычного Telegram Bot API есть ограничение: бот может **отправить**
файл размером не больше **50 МБ**. Загрузить видео *в* Telegram можно
и весом до 2 ГБ, а вот именно отправить его *от имени бота* — только
до 50 МБ, если не поднимать отдельный локальный сервер (см. вариант C).

Варианты решения (выберите один):

**Вариант A — сжать видео до <50 МБ (проще всего).**
Например, через ffmpeg:
```bash
ffmpeg -i original.mp4 -vf scale=-2:1080 -c:v libx264 -b:v 2300k -b:a 128k welcome.mp4
```
Положите результат в `assets/welcome.mp4` — бот отправит его напрямую
с диска, ничего в `config.py` менять не нужно.

**Вариант B — получить file_id (рекомендуется, если хотите оставить
исходное качество/размер как есть).**
1. Запустите `python get_file_id.py`.
2. В самом Telegram отправьте видео своему боту как обычное видео-сообщение
   (не файлом-документом) — от вас как от пользователя лимит на закачку
   в Telegram — 2 ГБ.
3. В консоли появится `file_id` — скопируйте в `.env` как
   `VIDEO_ABOUT_FILE_ID=...` (и, если нужно, `VIDEO_LESSON_FILE_ID=...`
   для отдельного видео бесплатного урока).
4. Дальше бот отправляет видео мгновенно по этому `file_id`, без
   повторной загрузки файла с диска.

**Вариант C — локальный Bot API сервер** (нужно, если у вас много
тяжёлых видео и вариант A/B не подходит). Поднимается `telegram-bot-api`
(официальный проект Telegram) на своём сервере, лимит на отправку
поднимается до 2 ГБ. Это отдельная инфраструктурная задача — если
понадобится, могу отдельно расписать конфигурацию.

## 5. Установка и локальный запуск

```bash
cd embrowbot
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
# откройте .env и впишите BOT_TOKEN (и, если получили, VIDEO_*_FILE_ID)

# способ 1: переменные окружения из .env подхватить вручную
export $(grep -v '^#' .env | xargs)   # Windows: используйте python-dotenv (см. ниже)

python bot.py
```

Если хотите, чтобы `.env` подхватывался автоматически (без `export`),
добавьте в начало `bot.py`:
```python
from dotenv import load_dotenv
load_dotenv()
```
и `pip install python-dotenv`.

## 6. Деплой на сервер (чтобы бот работал 24/7)

Любой из вариантов подойдёт, я перечислю от простого к более гибкому:

- **Railway / Render / Fly.io** — залить репозиторий, задать `BOT_TOKEN`
  как переменную окружения в панели, команда запуска `python bot.py`.
- **VPS (например, обычный Ubuntu-сервер)** — самый гибкий и дешёвый
  вариант, особенно если позже понадобится Вариант C с видео (локальный
  Bot API сервер). Через `systemd`-юнит бот будет автоматически
  перезапускаться при падении/перезагрузке сервера.
- **Docker** — тоже можно завернуть в контейнер, если у вас уже есть
  инфраструктура на Docker/Kubernetes.

## 7. Что можно донастроить дальше

  (на каждом из 3 языков). Пришлите фото/видео до-после, отзывы,
  сертификаты — добавлю `send_media_group` / несколько
  `send_photo`/`send_video` с реальным контентом.
- **Отдельное видео по языкам** — см. раздел 2 выше.
- **Аналитика/статистика** нажатий (сколько дошло до "Купить курс" и т.п.)
  — можно добавить логирование действий пользователей в файл или БД.
